Question 1: Evaluate the following definite integrals with all the required steps.

1. ∫14 (x − 3/√x) dx[cite: 21]

  • Step 1: Find the antiderivative using the power rule.
    Rewrite the integrand as x − 3x−1/2 (Herman & Strang, 2024).
    The antiderivative is [ (x2 / 2) − 3(x1/2 / (1/2)) ] = [ (x2 / 2) − 6√x ].
  • Step 2: Evaluate using the Fundamental Theorem of Calculus Part 2.
    Evaluate at upper limit 4: (42 / 2) − 6√4 = (16 / 2) − 6(2) = 8 − 12 = −4.
    Evaluate at lower limit 1: (12 / 2) − 6√1 = 0.5 − 6 = −5.5.
    Subtract the lower limit value from the upper: −4 − (−5.5) = 1.5.
  • Final Answer: 3/2 (or 1.5)

2. ∫12 (e−x + 1)2 dx[cite: 21]

  • Step 1: Expand the integrand algebraically.
    ( e−x + 1)(e−x + 1) = e−2x + 2e−x + 1.
  • Step 2: Find the antiderivative term by term.
    [ −(1/2)e−2x − 2e−x + x ].
  • Step 3: Evaluate limits.
    Upper limit (2): −(1/2)e−4 − 2e−2 + 2.
    Lower limit (1): −(1/2)e−2 − 2e−1 + 1.
    Subtract: (−(1/2)e−4 − 2e−2 + 2) − (−(1/2)e−2 − 2e−1 + 1)
  • Final Answer: −(1/2)e−4 − (3/2)e−2 + 2e−1 + 1

3. ∫0π/6 (sin 3x − cos x) dx[cite: 21]

  • Step 1: Find the antiderivative.
    [ −(1/3)cos(3x) − sin(x) ].
  • Step 2: Evaluate limits.
    Upper limit (π/6): −(1/3)cos(π/2) − sin(π/6) = −(1/3)(0) − 1/2 = −1/2.

4. ∫−40 (4 / (5 − 2x)) dx[cite: 21]

  • Step 1: Use u-substitution.
    Let u = 5 − 2x. Therefore, du = −2 dx, which means dx = −du / 2.
    Change limits: When x = 0, u = 5. When x = −4, u = 13.
    The integral becomes: ∫135 (4 / u)(−du / 2) = −2 ∫135 (1 / u) du.
  • Step 2: Integrate and evaluate.
    Flip limits to remove negative: 2 ∫513 (1 / u) du = 2[ ln|u| ]513.
    Evaluate: 2ln(13) − 2ln(5) = 2ln(13/5).
  • Final Answer: 2ln(13/5)

5. ∫π/4π/2 sin(2x − π/4) dx[cite: 21]

  • Step 1: Find the antiderivative.
    Using substitution u = 2x − π/4, the antiderivative is −(1/2)cos(2x − π/4).
  • Step 2: Evaluate limits.
    Upper limit (π/2): −(1/2)cos(2(π/2) − π/4) = −(1/2)cos(3π/4) = −(1/2)(−√2/2) = √2/4.

    Subtract: (√2/4) − (−√2/4) = 2√2/4 = √2/2.
  • Final Answer: √2/2

Question 2: The Area Under the Curve

Using substitution, determine the exact value of the total area bounded by the curve y = 4x / (x2 + 1) and the x-axis within the interval x = 0 and x = √(e2 − 1)[cite: 22].

  • Step 1: Set up the definite integral for area.
    Area = ∫0√(e²−1) [4x / (x2 + 1)] dx
  • Step 2: Apply u-substitution.
    Let u = x2 + 1 (Herman & Strang, 2024). Therefore, du = 2x dx.
    The numerator 4x dx is equal to 2du.
    Find the new u limits of integration:
    Lower limit: When x = 0, u = 02 + 1 = 1.
    Upper limit: When x = √(e2 − 1), u = (√(e2 − 1))2 + 1 = e2 − 1 + 1 = e2.
  • Step 3: Rewrite and evaluate the integral in terms of u.
    ∫1e² (2 / u) du = 2 [ ln|u| ]1e²
    Evaluate at limits: 2(ln(e2) − ln(1)).
    Because ln(e2) = 2 and ln(1) = 0, the equation simplifies to 2(2 − 0).
  • Final Answer: The exact area is 4.

Question 3: Application of Integration

The diagram shows a portion of the curve given by y = ecos x sin x and its maximum point D[cite: 22].

1. Find the coordinate of D.

  • Step 1: Find the first derivative y' using the Product and Chain rules.
    y' = (ecos x · (−sin x) · sin x) + (ecos x · cos x)
    y' = ecos x(cos x − sin2 x)
  • Step 2: Set y' to zero to find the critical point (maximum).
    Because ecos x is never zero, we set the inner bracket to zero: cos x − sin2 x = 0.
    Using the Pythagorean identity sin2 x = 1 − cos2 x, substitute this in:
    cos x − (1 − cos2 x) = 0 → cos2 x + cos x − 1 = 0.
    Treat this as a quadratic equation where v = cos x: v2 + v − 1 = 0.
    Using the quadratic formula: v = (−1 ± √(1 − 4(1)(−1))) / 2 = (−1 ± √5) / 2.
    Because cos x must be between −1 and 1 on this interval, we reject the negative root. Thus, cos x = (√5 − 1) / 2.
  • Step 3: Solve for the x and y coordinates.
    The x coordinate is exactly arccos((√5 − 1) / 2).
    To find the y coordinate elegantly, recall our previous identity where cos x = sin2 x. This means sin x = √(cos x).
    Substitute these into the original equation y = ecos x sin x to get:
    y = e((√5 − 1) / 2) · √((√5 − 1) / 2)
  • Final Answer (Coordinate D): [ arccos((√5 − 1) / 2) , e((√5 − 1) / 2) · √((√5 − 1) / 2) ]

2. Determine the exact value of the area of the shaded region bounded by the curve and the x-axis within the interval x = 0 and x = π.
